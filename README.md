# 📺 Netflix Data Analysis using PostgreSQL
[This is netflix image]:https://github.com/kumaran1523/Netflix_Sql_Projects_1/blob/main/netflix-logo.png
## 📌 Project Overview

This project analyzes the **Netflix Movies and TV Shows** dataset using **PostgreSQL**. The objective is to solve real-world business problems using SQL by performing **data exploration, aggregation, filtering, ranking, window functions, and string manipulation**.

The project demonstrates SQL skills commonly required for **Data Analyst**, **SQL Developer**, and **Business Analyst** roles.

---

## 🎯 Objectives

- Analyze Netflix Movies and TV Shows data.
- Solve business-related SQL problems.
- Practice advanced SQL queries.
- Improve data exploration and analytical thinking.
- Build a portfolio-ready SQL project.

---

## 🛠️ Tech Stack

- **PostgreSQL**
- **SQL**
- **pgAdmin 4**

---

## 📂 Dataset

The dataset contains information about Netflix content, including:

- **Show ID**
- **Type** (Movie / TV Show)
- **Title**
- **Director**
- **Cast**
- **Country**
- **Date Added**
- **Release Year**
- **Rating**
- **Duration**
- **Genre**
- **Description**

---

## 📊 Business Problems Solved

This project includes solutions for **15 real-world SQL business questions**, such as:

1. Count the number of **Movies** and **TV Shows**.
2. Find the **most common rating** for each content type.
3. List all **movies released in a specific year**.
4. Find the **top countries** with the most Netflix content.
5. Identify the **longest movie**.
6. Find content **added in the last few years**.
7. Search content by **director**.
8. Analyze **TV Shows with multiple seasons**.
9. Count content by **genre**.
10. Find **yearly content release trends**.
11. Analyze **ratings distribution**.
12. Identify movies by **duration**.
13. Perform **country-wise content analysis**.
14. Explore **genre-based insights**.
15. Solve additional business queries using **SQL functions**.

  - `string_to_array()`
